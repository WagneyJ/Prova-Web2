# GamePulse

Portal de notícias sobre games criado para a atividade de Desenvolvimento Web 2.

### Paleta

- Fundo: #F4F1FF
- Cards: #FFFFFF
- Texto: #22202A
- Texto secundário: #6D6978
- Roxo principal: #6848D8
- Roxo claro: #ECE7FF

### Fontes

- Roboto Slab: títulos e logotipo.
- Nunito: textos, menus e botões.

### Imagens

As imagens são exemplos gerados pelo Lorem Picsum:
https://picsum.photos/

## JavaScript

O projeto utiliza JavaScript puro para:

1. Filtrar notícias por categoria.
2. Pesquisar notícias.
3. Mostrar mais notícias.
4. Alternar entre modo claro e escuro.
5. Validar o formulário de e-mail.

## Responsividade

O CSS utiliza Grid e Flexbox e possui breakpoints para telas menores.
